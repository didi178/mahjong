# @mahjong/ui-components

Visual components for tiles, racks, and target comparison.

## Purpose

- Tile rendering
- Rack display
- Target/hand comparison UI
- Reusable game UI widgets

## Design Principles

- **Presentation only**: No game logic
- **Legality via props**: UI queries rules-engine, doesn't encode legality
