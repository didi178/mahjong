# @mahjong/tile-model

Tile identities, counts, and serialization.

## Purpose

This package defines:
- Tile types and identities
- Tile counts and availability
- Canonical JSON serialization format
- Tile equality and comparison

## Design Principles

- **Deterministic**: No randomness in tile definitions
- **Immutable**: Tile identities are values, not objects with state
- **Canonical**: Single source of truth for tile representation
