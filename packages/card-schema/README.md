# @mahjong/card-schema

Schema and validation for practice cards.

## Purpose

This package defines:
- Card structure and format (YAML/JSON schema)
- Validation rules for card definitions
- Type exports for card AST

## Design Principles

- **Content-driven**: Cards are data, not code
- **Validated**: Schema enforcement at load time
- **Type-safe**: Full TypeScript types for card structure
